Learnings from Phase 9:
- When calling `isProUser`, always make sure to pass `user?.email` (so that Owner bypass logic correctly overrides free-tier quotas). The `user` object needs to be accurately destructured and maintained inside context state.
- Ensure any added property to an interface (like `guardianPhone`) matches throughout the codebase to avoid TS compilation errors.
- Always use `.some` or fallback safely (`foo || 'fallback'`) to handle missing properties cleanly across older/imported profiles.
